# ENA Safari Hauler: Kenya Bus & Truck Simulator 🇰🇪

A 3D simulation game inspired by *Euro Truck Simulator*, set on the highways of Kenya
(the Northern Corridor: Nairobi – Nakuru – Kericho – Kisii – Kisumu).

The game features authentic real-world Kenyan commercial vehicles from the **ENA Group**:

- 🚌 **Scania Master Apollo (8 Wheels / 4 Axles)**: Kenya's legendary multi-axle luxury highway
  cruiser built by Master Fabricators on a Scania K-series chassis. Features **twin front
  steering axles (4 steer wheels)**, Scania chrome grille with Griffin crest, aerodynamic
  sunvisor brow with 5 amber clearance LEDs, panoramic split windshield, elephant-ear
  side mirrors, Alcoa chrome rims, and VIP passenger comfort mechanics.
- 🚚 **Isuzu FRR Logistics (6 Wheels / Dual Rear)**: The undisputed king of Kenyan freight
  haulage (Isuzu East Africa Forward FRR 90). Built with a **6-wheel setup featuring
  twin dual-tire rear drive wheels**, welded Kenyan steel front bull-bar (*kikapu*),
  vertical snorkel air intake stack, exposed ladder chassis with aluminum diesel tank,
  battery box, under-chassis spare tire, and corrugated EPH parcel freight box.

---

## 🎮 How to Play the Prototype

Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Brave, etc.).
No installation or web server required!

### 🕹️ Controls

| Key | Action |
| :--- | :--- |
| **W / ▲** | Accelerate / Drive Forward |
| **S / ▼** | Brake / Reverse |
| **A / D** | Steer Wheels Left / Right |
| **H** | Authentic Horn (Melodic chime for ENA Bus, deep blast for EPH Truck) |
| **C** | Toggle Camera (Chase View ⇄ Driver's Cabin) |
| **V** | Open Fleet Garage (Switch between ENA Coach & EPH Truck) |

---

## 🛣️ Key Gameplay Mechanics

- **Left-Hand Traffic**: Faithful to Kenyan road rules.
- **Speed Bumps & Rumble Strips**: Bumps physically jolt the vehicle suspension.
  Hitting them too fast causes passengers to complain (*"Dereva, pole pole!"*) or
  damages fragile EPH parcel cargo.
- **Dynamic HUD**: Real-time speedometer (km/h), gear indicator, and Passenger
  Comfort / Parcel Integrity gauge.
