# ENA Safari Hauler: Kenya Bus & Truck Simulator 🇰🇪

A 3D simulation game inspired by *Euro Truck Simulator*, set on the highways of Kenya (the Northern Corridor: Nairobi – Nakuru – Kericho – Kisii – Kisumu).

The game features the **ENA Group dual-fleet ecosystem**:
- 🚌 **ENA Coach**: Luxury long-distance passenger coach with realistic highway cruising, VIP marquee destination signage, authentic chime horn, and passenger comfort mechanics.
- 🚚 **EPH Logistics (ENA Parcel Handlers)**: Heavy courier parcel box truck with rugged bull-bar (*kikapu*), parcel integrity meter, and deep diesel pneumatic air horn.

---

## 🎮 How to Play the Prototype
Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Brave, etc.). No installation or web server required!

### 🕹️ Controls
| Key | Action |
| :--- | :--- |
| **W / ▲** | Accelerate / Drive Forward |
| **S / ▼** | Brake / Reverse |
| **A / D** | Steer Wheels Left / Right |
| **H** | Authentic Horn (Melodic chime for ENA Bus, deep blast for EPH Truck) |
| **C** | Toggle Camera (Chase View ⇄ Driver's Cabin) |
| **V** | Open Fleet Garage (Switch between ENA Coach & EPH Truck) |

---

## 🛣️ Key Gameplay Mechanics
- **Left-Hand Traffic**: Faithful to Kenyan road rules.
- **Speed Bumps & Rumble Strips**: Bumps physically jolt the vehicle suspension. Hitting them too fast causes passengers to complain (*"Dereva, pole pole!"*) or damages fragile EPH parcel cargo.
- **Dynamic HUD**: Real-time speedometer (km/h), gear indicator, and Passenger Comfort / Parcel Integrity gauge.
